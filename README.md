# Lifestyle Properties Website

A responsive real estate landing page built using HTML and CSS.

## Features

* Clean and semantic HTML structure
* Responsive hero section using Flexbox
* Sticky navigation bar
* Styled form with input fields and radio buttons
* Mobile-friendly layout

## Built With

* HTML5
* CSS3 (Flexbox)

## Responsiveness

The layout adjusts to different screen sizes, including mobile devices.
Flexbox and relative units were used to ensure proper alignment and spacing.

## What I Learned

* Structuring a webpage using semantic HTML
* Centering elements using Flexbox and text alignment
* Creating responsive layouts
* Styling forms and inputs
* Using `position: sticky` for navigation

## Future Improvements

* Add more sections (property listings, footer)
* Improve mobile responsiveness further
* Add JavaScript for interactivity
* Enhance UI design
